# Favour Makeup Website

## About the Project

This project is a responsive website developed for Favour Makeup, a beauty business based in Fourways. The website provides information about the business, its services, makeup gallery, booking information and contact details.

## Website Goal

The main goal of the website is to create a professional and user-friendly online platform where customers can learn more about Favour Makeup, view makeup services, explore previous work, make booking enquiries and find contact information.

## Website Objectives

- Provide information about Favour Makeup and its services.
- Allow customers to view makeup work through the gallery.
- Provide an easy-to-use booking form.
- Make contact information easily accessible.
- Ensure the website works across desktop, tablet and mobile devices.
- Improve the overall visual appearance and usability of the website.

## Design

The website uses a simple beauty-focused design with a black, white and pink colour scheme.

Arial is used as the main font to keep the website clear and easy to read.

CSS Flexbox and Grid were used to organise the website content and create a structured layout.

## Responsive Design

The website was designed to work across different screen sizes.

The website was tested on:

- Desktop
- Tablet
- Mobile

CSS media queries were used to adjust the layout, navigation, typography, images and content for smaller screens.

The navigation changes to a vertical layout on smaller screens, while gallery images and content adjust to fit the available screen width.

# Favour Makeup Website

## Project Overview

Favour Makeup is a beauty business website designed to introduce visitors to the business, showcase its services and products, and allow visitors to make enquiries.

## Part 3: Enhancing Functionality and SEO

### JavaScript Functionality

JavaScript was used to add interactive features to the website, including:

- Automatic display of the current year in the footer.
- Product search functionality.
- Frequently Asked Questions accordion.
- Image gallery lightbox.
- Scroll reveal animations.
- Client-side form validation.
- Enquiry responses based on the selected enquiry type.

### Interactive Map

A Google Maps embed was added to the contact page to display the Fourways area in Johannesburg.

The map displays the general area and does not represent a verified street address for the business.

### Search Engine Optimisation

SEO improvements include:

- Unique page titles.
- Meta descriptions for all website pages.
- Relevant keywords in page content.
- Structured heading tags.
- Descriptive image filenames.
- Alternative text for images.
- Internal navigation links.
- robots.txt file.
- sitemap.xml file.

### Form Functionality

The enquiry form collects information about services, products and other opportunities.

The contact form collects general messages and prepares an email using the visitor's email application when the business email address is configured.

Client-side validation checks required fields and email addresses.

### Performance and Accessibility

The website includes responsive layouts, image loading improvements, keyboard focus indicators and reduced-motion support.
